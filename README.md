# محوّل الصور (AVIF و WebP إلى JPG)

أداة بتحوّل صور AVIF و WebP لصيغة JPG جوه المتصفح. الصور مش بتترفع على أي سيرفر، والسيرفر بيعرض الصفحة بس وبيحميها بصفحة دخول.

## المميزات

- تحويل كذا صورة مرة واحدة، صورتين في نفس الوقت عشان الموبايل ميهنجش.
- الأجزاء الشفافة بتبقى بيضا بدل سودا.
- تنزيل كل صورة لوحدها، أو الكل في ملف مضغوط بأسماء مش متكررة.
- صفحة دخول تقدر برامج كلمات السر (زي Bitwarden) تملاها، والدخول يفضل 180 يوم.

## التشغيل على الجهاز

```bash
npm install
npm run dev          # http://localhost:3000
npm run lint         # فحص الأنواع
npm run build        # بيبني الواجهة والسيرفر في dist/
npm start            # تشغيل نسخة الإنتاج
```

## متغيرات البيئة

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `APP_USERNAME` | `user` | اسم المستخدم في صفحة الدخول |
| `APP_PASSWORD` | فاضي | كلمة السر. لو فاضية الموقع يبقى مفتوح للكل |
| `SESSION_DAYS` | `180` | مدة الدخول بالأيام |
| `SESSION_SECRET` | فاضي | مفتاح توقيع اختياري للجلسة |
| `APP_DOMAIN` | `jpg.aaaaaaaaa9000.cloud` | الدومين اللي Traefik بيوجّه له |
| `PORT` | `3000` | البورت جوه الكونتينر |

مش محتاج مفتاح Gemini، التطبيق مش بيستخدم ذكاء اصطناعي.

## الرفع على السيرفر (Portainer)

Stack من الريبو ده، فرع `main`، ملف `docker-compose.yml`، باسم `ai-app-jpg`، ومعاه `APP_PASSWORD` في متغيرات البيئة. الكونتينر بيتوصل بشبكة `automation-stack_automation-network` و Traefik بيعمل الشهادة تلقائي.
